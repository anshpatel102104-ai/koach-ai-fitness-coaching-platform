# KOACH AI

Premium AI-powered fitness coaching platform. React + Vite frontend on Supabase
(Auth, Postgres, Storage, Edge Functions).

## Local development

1. Clone the repository and install dependencies: `npm install`
2. Copy `.env.example` to `.env.local` and set `VITE_SUPABASE_URL` and
   `VITE_SUPABASE_ANON_KEY`.
3. Run the app: `npm run dev`

See [DEPLOYMENT.md](./DEPLOYMENT.md) for deployment and environment variables.
